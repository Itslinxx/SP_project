# SP_project
На основе дообучения ResNet-34 на CIFAR-10 реализованы PGD-атака, состязательное обучение и сглаживание меток (label smoothing), а также их комбинация. Для каждого подхода измеряется точность на тестовой выборке и вычисляется деградация относительно стандартного дообучения.

Обученные модели хранятся в папке models.
Залогированные метрики хранятся в папке logs.
Весь код оформлен в виде единого ноутбука sp_prog.ipynb
